تثبيت نظام المبيعات كتطبيق (PWA)
==================================
1) أنشئ حساب مجاني على github.com ثم New repository باسم pos (خليه Public).
2) اضغط Add file ثم Upload files وارفع كل ملفات هذا المجلد (index.html و manifest.webmanifest و sw.js و الأيقونات) ثم Commit.
3) من Settings ثم Pages: اختر Deploy from a branch والفرع main والمجلد root ثم Save.
4) بعد دقيقتين بيصير الرابط: https://اسم-حسابك.github.io/pos/
5) افتح الرابط على جهاز العميل:
   - كمبيوتر (Chrome أو Edge): أيقونة التثبيت بشريط العنوان ثم تثبيت.
   - أندرويد (Chrome): القائمة ثم تثبيت التطبيق.
   - آيفون (Safari): مشاركة ثم إضافة إلى الشاشة الرئيسية.
6) فعّل النظام بمفتاح من أداة license-keygen-PRIVATE (رقم الجهاز بيظهر بشاشة التفعيل).

لتحديث النظام لاحقاً: ارفع index.html الجديد وغيّر رقم النسخة بملف sw.js (من pos-v1 إلى pos-v2) ثم Commit. العملاء بيستلموه تلقائياً.

تنبيهات:
- بيانات كل جهاز ومتصفح محفوظة عليه فقط. لا تمسح بيانات الموقع. خذ نسخة احتياطية من الإعدادات.
- الجهاز الذي يفتح الرابط من متصفح آخر بيحتاج تفعيل جديد.
